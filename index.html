How it works

The skill checks only what the diff changed, runs only the rules that apply, and checks each finding once more before it reports it.

Find the change

Reads the diff. With no UI file, it says so and stops.

Map the surfaces

Tags each surface with its kinds: write, list, overlay…

Pick the rules

Runs each rule whose kinds match. The repo's own UI rules come first.

Read, then measure

Code first. Then boxes, gaps and shifts at rest, on hover and on focus.

Check and report

Re-measures each finding, and keeps defects the diff did not add apart.

// Load the skill's helpers, then measure a hover
await page.addScriptTag({ path: "scripts/measure.js" });
await page.evaluate(() => snapshot(".item", "rest"));
await page.hover("text=Your requests");
await page.evaluate(() => gaps(".item"));
// → [{ from: "Home", to: "Your requests", y: 0 }]
await page.evaluate(() => moved("rest", "hover"));
// → []   hover moved nothing
**Surface:** Sidebar nav, “Your requests” hovered
**Rule:** `no-cramped-controls`
**Evidence:** `gaps(".item")` at 1440px, row 2
hovered: y: 0 between “Home” (selected) and
“Your requests”. At rest the gap is also 0, but
only the selected row draws a box.
**Fix:** Add `gap: 2px` to the list.
